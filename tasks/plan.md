# แผน v9 (branch `claude/hd-3d-remaster`): ทำให้ผีน่ากลัว ไม่ตลก

แผน v8 (HD remaster, คนสมจริง, เฟอร์นิเจอร์สมจริง, เสียงใหม่) เสร็จแล้ว ย้ายไป `tasks/archive/v8-plan.md`
จุดตั้งต้น: เทสต์ผ่าน 493 ข้อ (ที่ไม่ผ่านมีแค่เกณฑ์ FPS บนเครื่องทดสอบที่ไม่มีการ์ดจอ)

## ปัญหาที่ต้องแก้ (จากผู้เล่น + จากโค้ด)
1. **"ตัวละครดูตลก"** สาเหตุหลักในโค้ด:
   - `Body.pose()` แกว่งขาและแขนทั้งท่อนเป็นไม้ตรงๆ (ไม่มีเข่า ศอก หลัง มือ) และขยับแบบกระตุก 12 fps (`npc.gd anim_fps`) พอใส่บนคนสมจริงเลยดูเหมือนหุ่นของเล่น
   - rig มีแค่ 7 กระดูก (`build_humans.py`) งอเข่า/ศอกไม่ได้
   - หน้าผีโผล่ชัดและสว่างในหลายที่ (jumpscare `_face_slam` เอาหัว 3D ที่จัดแสงสวยมาพุ่งใส่จอ) แต่หน้าคนสมจริงที่สว่างชัดไม่น่ากลัว
   - ผีกลางคืนใส่เสื้อผ้าแบบเดียวกับกลางวัน ต่างกันแค่ตาเรือง
2. ความกลัวยังมาจาก "ไล่ + jumpscare" เป็นหลัก ผู้เล่นเคยขอความหลอนเชิงจิตวิทยา
3. เสียงใหม่ยังไม่มีคนฟังจริง ยังไม่มีเสียงบอกว่าผีตัวไหนอยู่ใกล้ และเสียงทะลุกำแพงได้
4. เวอร์ชันเว็บหนักขึ้น (ไฟล์ 25MB, ตัวละครตัวละ ~35k สามเหลี่ยม)

## แนวคิดหลัก
- **น้อยแต่ได้ผล:** ให้เห็นผีเป็นเงา เป็นท่าทางผิดธรรมชาติ ได้ยินก่อนเห็น ไม่ใช่เห็นหน้าชัดๆ
- **ท่าทางผิดที่ผิดทาง** น่ากลัวกว่าหน้าตา: เดินตัวแข็งแต่หัวหันตามเรา หยุดนิ่งตอนถูกมอง กระตุกตอนเราหันไป
- ทุกอย่างทำผ่านระบบที่มีอยู่แล้ว (`Body` stand-in parts, `director.gd`, `Game.sfx`, `HD.dress`) ไม่ต้องรื้อฉากที่ bake ไว้
- ภาพย้อนยุค (PSX) ต้องเหมือนเดิมทุกอย่าง งานภาพทั้งหมดอยู่หลัง `not Game.retro`

## ลำดับการพึ่งพา
```
T1 rig มีเข่า/ศอก/หลัง/คอ ──> T2 ท่าเดินและท่าหลอนของผีแต่ละตัว
                         └──> T3 ร่างกลางคืน (หน้าในเงา เสื้อผ้าเปื้อน)
T4 jumpscare แบบไม่โชว์หน้าชัด (อิสระ)
T5 ตารางความดังเสียงที่เดียว ──> T6 เสียงประจำตัวผี
                             └──> T7 เสียงทะลุกำแพงจะอู้อี้
                             └──> T8 ดนตรีตามสถานการณ์
T9 ของในฉากเปลี่ยนตอนหันหลัง (อิสระ ใช้เฟอร์นิเจอร์จริงที่เพิ่งทำ)
T10 ภาพหลอนตอน Social Battery ต่ำ (หลัง T2: ใช้ท่าใหม่)
T11 ประสิทธิภาพเว็บ (อิสระ ทำหลังเปลี่ยนโมเดล T1/T3)
T12 เทสต์ทั้งหมด เอกสาร เว็บ push (ท้ายสุด)
```

## วิธีตรวจ (ใช้ทุกงาน)
- เทสต์เฉพาะ: `xvfb-run -a -s "-screen 0 960x720x24" godot --rendering-driver opengl3 --path . res://tests/tests.tscn -- t_<ชื่อ>`
- เทสต์เต็ม: คำสั่งเดียวกันไม่ใส่ชื่อ (~35 นาที)
- สร้างตัวละครใหม่: `python tools/blender/build_humans.py` (pip `bpy`) หรือ `blender -b -P tools/blender/build_humans.py`
- เว็บ: ย้าย `tmp_probe/` ออกก่อน แล้ว `godot --headless --export-release "Web" docs/index.html`
- ดูภาพ: `tmp_probe/props.tscn` (เรียงโมเดล), `tmp_probe/probe.tscn -- look <บท>:desk` (มุมในเกม)
