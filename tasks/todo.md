### T2: ท่าเคลื่อนไหวใหม่ของผี
**ทำอะไร:** `Body.pose()` แบบลื่น (เลิกกระตุก 12 fps บนตัวสมจริง) เดินงอเข่า แกว่งแขนงอศอก ตัวโยกเล็กน้อย เพิ่มท่าเฉพาะตัว: หัวหน้าธนาเดินตัวตรงแข็ง หัวหันตามผู้เล่นตลอด, ป้าพรลากขาข้างหนึ่ง, เต้ห่อตัวกระตุกเป็นพักๆ, พี่สมชายยืนนิ่งเป๊ะไม่หายใจ, HR เดินส้นสูงเร็วเกินคน เพิ่ม "หยุดนิ่งตอนถูกมอง" (ค้างท่ากลางก้าว) ให้ทุกตัวที่ไม่ได้ไล่อยู่
**เกณฑ์ผ่าน:**
- [x] ผีแต่ละตัวมีท่าเดินของตัวเอง (`anim_mode` ไม่ซ้ำกัน)
- [x] ตอนเดิน เข่าและศอกงอเป็นจังหวะ ไม่มีเฟรมที่แขน/ขาตรงทั้งท่อน
- [x] ผีที่ไม่ได้ไล่และอยู่ในสายตา ค้างท่าภายใน 0.2 วินาที
**ตรวจ:**
- [x] เทสต์ใหม่ `t_creep_gaits` (มุมเข่า/ศอกระหว่างเดิน, ค้างท่าตอนถูกมอง) + `t_chase_gives_up`, `t_director` ผ่าน
- [x] คลิปภาพ (probe) เดินของแต่ละตัวให้เจ้าของเกมดู
**ขึ้นกับ:** T1
**ไฟล์:** `scripts/body.gd`, `scripts/npc.gd`, `scripts/mobs/*.gd` (เฉพาะค่า anim_mode), `tests/tests.gd`
**ขนาด:** M

### T3: ร่างกลางคืนที่น่ากลัว
**เจ้าของเกมเลือก:** หน้าบิดเบี้ยว ยิ้มกว้างผิดปกติ (ทำด้วย `distort()` ขยับโครงหน้าจริง ไม่ใช่ระบายสี)
**ทำอะไร:** ใน `build_humans.py` ร่าง `_night` ได้: ผิวซีดอมเขียว เบ้าตาและแก้มตอบเป็นเงาเข้ม (vertex colour + เพิ่ม AO บนหน้า) ปากเปื้อน เสื้อผ้ามีคราบและสีหม่น ท่ายืนห่อไหล่คอยื่น (ตั้งค่า rest ของ Chest/Neck) ใน Godot วัสดุผิวกลางคืนสะท้อนแสงน้อยลง ไม่มี rim light
**เกณฑ์ผ่าน:**

- [x] ร่างกลางวันในบทนำเหมือนเดิม
**ตรวจ:**
- [x] ภาพเรียงตัวกลางวัน vs กลางคืน + ภาพในเกมใต้ไฟฉาย
- [x] `t_models`, `t_tutorial` ผ่าน
**ขึ้นกับ:** T1 (ใช้ Chest ทำท่าห่อ)
**ไฟล์:** `tools/blender/build_humans.py`, `scripts/body.gd` (`real_mat`), `assets/characters/real/*_night.*`
**ขนาด:** M

**เกณฑ์ผ่าน:**
- [x] ผีทุกตัวมีเสียงประจำตัว ได้ยินชัดที่ระยะ 8–12 m
- [x] เสียงหยุดเมื่อผีหยุดนิ่ง (รวมตอนค้างท่าเพราะถูกมอง)
**ตรวจ:** เทสต์ใหม่ `t_ghost_cues` + ฟังในเกม
**ขึ้นกับ:** T5

### T7: เสียงหลังกำแพงอู้อี้
**ทำอะไร:** เสียง 3D ของผีและเหตุการณ์ ยิง ray จากผู้เล่นไปหาแหล่งเสียงทุก 0.2 วินาที ถ้าโดนกำแพงลด `attenuation_filter_cutoff_hz` และความดังลง
**เกณฑ์ผ่าน:**
- [x] แหล่งเสียงหลังกำแพงมี cutoff ≤ 1500 Hz, ในที่โล่ง ≥ 5000 Hz
**ตรวจ:** เทสต์ใหม่ในแผนที่ทดสอบที่มีกำแพงกั้น
**ขึ้นกับ:** T5
**ไฟล์:** `scripts/game.gd`, `tests/tests.gd`
**ขนาด:** S

### T8: ดนตรีตามสถานการณ์
**ทำอะไร:** สถานะเพลง สงบ → ไม่สบายใจ (ผีอยู่ใกล้แต่มองไม่เห็น) → ไล่ → หลังรอด (เงียบ + หัวใจค่อยๆ ช้าลง) และเสียงกระแทกเบาๆ ตอนเห็นผีครั้งแรกในบท เพิ่มชั้นเสียง "ไม่สบายใจ" ใน `synth_horror.py`

**ขึ้นกับ:** T5
